Every release has a build for the hardware: the `freesp16` file, and the same file in a `.tar.gz` with its licences.
A ready-made Linux desktop build isn't published yet; until it is, [build it from source](/contribute/#build) (the same
code as the hardware build). On the hardware, freesp16 is started by the community
[boot menu](https://github.com/freesp16/bootmenu), which you download once; see the
[install guide](/install/hardware/).

<Downloads />

## Check your download

Each release lists the SHA-256 checksum of every file. To check a download on Linux or macOS:

```sh
sha256sum autoexec.bin freesp16
```

On Windows (PowerShell):

```powershell
Get-FileHash autoexec.bin, freesp16 -Algorithm SHA256
```

Each printed value must match the one on its release page (freesp16's or the boot menu's).

<Aside type="caution" title="Only download from this site or GitHub">
	Official builds are published only on the GitHub releases pages of
	[freesp16](https://github.com/freesp16/freesp16/releases) and of the
	[boot menu](https://github.com/freesp16/bootmenu/releases). Don't run an `autoexec.bin` or a `freesp16` from
	anywhere else on your instrument.
</Aside>
